# Пакет документов: анализ и ТЗ для переезда сайта кондитерской на новый стек

Собрано на основе: архива исходного кода сайта `abrikosova-elena.ru` (Django) и юридического договора с Приложением №1 (техническое задание, уже фиксирующее целевой стек: Next.js 15/React 19/TS/Tailwind 4 + FastAPI/SQLAlchemy 2/PostgreSQL).

## Структура пакета

```
analysis/
  ANALYSIS.md               — аудит текущей реализации: архитектура, найденные баги и риски, сверка с новым ТЗ
spec/
  00-overview.md             — цель проекта, стек, структура монорепо, инженерные принципы
  01-data-model.md           — модель данных (SQLAlchemy) + план seed-данных
  02-api-contract.md         — REST API контракт (FastAPI)
  03-pages-wireframes.md     — текстовые блок-схемы всех страниц (mobile + desktop)
  04-admin-panel.md          — спецификация админ-панели
  05-nonfunctional-and-acceptance.md — безопасность, SEO, интеграции, out-of-scope, критерии приёмки
  06-implementation-plan.md  — пошаговый план для Claude Code
wireframes/skeleton/
  index.html, home.html, catalog.html, product.html, ...
                              — визуальные серые skeleton-вайрфреймы (открыть index.html в браузере)
```

## С чего начать

1. Прочитать `analysis/ANALYSIS.md` — чтобы понимать, откуда взялись те или иные решения в `spec/`.
2. Прочитать `spec/00-overview.md` → `01` → `02` → `03` по порядку — это и есть готовое ТЗ.
3. Открыть `wireframes/skeleton/index.html` в браузере (просто как файл, сборка не нужна) — визуальное сопровождение к `spec/03-pages-wireframes.md`.
4. Всю папку `spec/` (плюс `wireframes/`) можно скормить Claude Code как контекст задачи — `spec/06-implementation-plan.md` написан как чек-лист этапов реализации.

## Важно

Это ТЗ **не описывает визуальный дизайн** (цвета, шрифты, иллюстрации) — макеты готовит отдельно приглашённый дизайнер. Здесь зафиксирована структура: данные, API, поведение, порядок и состав блоков на каждой странице.
