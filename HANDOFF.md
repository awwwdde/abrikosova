# Точка входа для новой сессии

Дата последнего обновления: 01.09.2026. Обновляй этот файл в конце каждой сессии.

## Что это за проект

Переписывание сайта кондитерской `abrikosova-elena.ru` со старого Django на Next.js 15 + FastAPI.
Пишем **с нуля** — код старого сайта не переносится.

```
new/     готовое ТЗ: analysis/ANALYSIS.md + spec/00..06 + wireframes/skeleton/*.html
old/     старый Django-сайт — ТОЛЬКО референс (бизнес-логика, тексты, структура каталога)
app/     сам проект: монорепо apps/web + apps/api
```

**Порядок чтения перед работой:** `new/spec/00-overview.md` → `01-data-model.md` → `02-api-contract.md`
→ `03-pages-wireframes.md`. План работ — `new/spec/06-implementation-plan.md`.

## Приоритет работ

**Сначала функционал, дизайн — потом.** Визуал сейчас на уровне вайрфрейма и намеренно там
и остаётся: макеты готовит дизайнер, после чего оформление применяется отдельным этапом
и не меняет структуру, API и модель данных. Не тратить время на доводку внешнего вида.

## Загрузка изображений — сделана

- Хранилище S3-совместимое: локально **MinIO** (сервис `minio` в compose, консоль на :9001),
  на проде — S3 Object Storage Timeweb Cloud. Код один, различается строка подключения.
- `POST /admin/products/{id}/images` (лимит 6, первое фото автоматически главное),
  `PATCH .../images/{id}` (сделать главным), `DELETE .../images/{id}` (с переназначением главного),
  `POST /admin/uploads?prefix=gallery|fillings|custom-cakes|reviews` для одиночных фото.
- Любой файл пересобирается в WEBP через Pillow: это отбрасывает EXIF (геометка, модель камеры),
  ужимает до 2000px по большей стороне и заодно исключает полезную нагрузку в метаданных.
  Проверяется содержимое, а не заголовок Content-Type; SVG не принимается; имя файла из запроса
  не используется — ключ случайный.
- Бакет создаётся при старте приложения, чтение объектов публичное, запись и листинг — только
  по ключам. Проверено: анонимные PUT и листинг → 403.
- В админке: блок фотографий в карточке товара (загрузка, «сделать главным», удаление) и загрузка
  фото работы в разделе «Примеры работ».
- На сайте — `next/image` с `sizes`; пока фото нет, показывается заглушка того же соотношения сторон.

**Важно про адреса медиа.** В разработке браузер и контейнер видят MinIO по разным именам, поэтому
`NEXT_PUBLIC_MEDIA_URL=/media`, а Next проксирует `/media/*` в `MEDIA_INTERNAL_URL=http://minio:9000/...`.
На проде обе переменные заменяются одним публичным доменом бакета, и `remotePatterns` заполняется
из него автоматически.

## Сброс кэша после правок — сделан

Публичные страницы отдаются с ISR (5 минут). Раньше правка из админки появлялась на сайте только
после истечения интервала. Теперь бэкенд после мутации товара или контента страниц дёргает
`POST /api/revalidate` на фронтенде и сбрасывает конкретные пути. Маршрут закрыт общим секретом
`REVALIDATE_SECRET` (сравнение с постоянным временем), принимает только внутренние пути.
Проверено: без секрета и с неверным — 401; правка названия товара видна на сайте сразу.

Контейнер `api` на старте сам накатывает миграции и сид.

## Особенности этой машины

- **Порты 5432 и 8000 заняты другим проектом** (`svidanie`). В `app/.env` заданы
  `POSTGRES_HOST_PORT=5433` и `API_HOST_PORT=8001`; дефолты в коде остались каноничными.
  `NEXT_PUBLIC_API_URL` в compose следует за `API_HOST_PORT` — если захардкодить, браузер упрётся
  в CORS (уже наступали).
- Серверные компоненты ходят в API по внутреннему имени `http://api:8000`, браузер — по публичному
  порту. Это разные переменные: `API_URL` и `NEXT_PUBLIC_API_URL`.
- `apps/api/.env` указывает на `localhost:5433` — для запуска API вне докера (venv в `apps/api/.venv`).
- Docker Desktop иногда выключен; если команды `docker` падают на pipe — запустить его.

## Решения, уже принятые (не пересматривать без причины)

- **Хостинг** — Timeweb Cloud: App Platform, Managed PostgreSQL, Managed Redis, S3 Object Storage.
  Build context — `app/apps/web` и `app/apps/api`.
- **Корзина** — один источник правды на бэкенде, httpOnly cookie `cart_id`, без localStorage.
- **Фоновые задачи** — `BackgroundTasks` для e-mail, APScheduler для бэкапов. Redis — кэш и rate-limit.
- **Админка** — route-группа `/admin` внутри того же Next.js-приложения.
- **UI-библиотека** — shadcn/ui по договору. В одной из сессий её убирали и вернули обратно —
  не убирать снова без прямого указания. Фактически сейчас в коде свои примитивы на Tailwind;
  при подключении shadcn их можно заменить без изменения структуры.
- **Контент старого сайта не мигрируется** — только seed-данные.
